# Weather in Class

A browser-based app that recommends what to wear based on the weather forecast, presented through a character whose outfit changes with conditions. Built for a US college student audience as part of a clothing brand's social-engagement campaign.

## Status

Early planning stage. See `brief.md` for the project brief, `research.md` for context and user research, `spec.md` for requirements, and `plan.md` for the build order.

## Project documents

- `brief.md` — client need and requirements
- `research.md` — context of use, user stories, reference analysis, weather research
- `spec.md` — testable requirements
- `plan.md` — build and verification task order
- `reference/` — reference images and hand-drawn screen sketches
- `transcripts/` — saved session transcripts
